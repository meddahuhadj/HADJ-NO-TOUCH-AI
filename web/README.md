# HADJ NO-TOUCH AI — PWA landing + live demo

A single-page, fully offline **Progressive Web App** that markets HADJ NO-TOUCH AI
(a Windows desktop app for contactless computer control via webcam hand gestures,
voice and gaze) and demonstrates the interaction live in the browser: your **mouse
acts as the air-pointer** over the canvas "virtual interaction plane" — pinch-click,
scroll and palm-mode included.

## What's inside

| File | Purpose |
| --- | --- |
| `index.html` | The page — semantic HTML5, verbose ARIA, canvas demo, install prompt |
| `styles.css` | Full "Mission-Control Glass" design system (no frameworks) |
| `app.js` | Interactivity: canvas demo, HUD, gestures, PWA install, SW registration |
| `manifest.webmanifest` | Installable PWA manifest (`standalone`, `#060912`, 192/512 + maskable icons) |
| `sw.js` | Cache-first service worker with versioned cache + offline fallback |
| `vercel.json` | Vercel static config (clean URLs + `no-cache` for `sw.js`) |
| `icons/` | Brand icon (`icon.svg`, PNG 192/512, maskable 512) — generated by `make_icons.py` |
| `assets/noise.png` | Film-grain texture for the background (generated) |
| `make_icons.py` | Reproduces all icon PNGs + grain locally with Pillow |

## Run locally

```bash
cd web
python -m http.server 8080
```

Open <http://localhost:8080> — the service worker and install button activate on
`localhost` and HTTPS. For a quick visual check you can skip the server and open
`index.html` directly (SW/install will be inactive, everything else works).

Regenerate icons after edits:

```bash
python make_icons.py      # or: py -3.12 make_icons.py
```

## Deploy to Vercel

1. Push this `web/` folder to a repo (or use the CLI).
2. `vercel` from the `web/` directory — framework preset: **Other / static**; build
   command: *none*; output: *current directory*.
3. Or in the Vercel dashboard: **Add New Project → Import → Framework Preset:
   Other** and point it at the folder.

`vercel.json` sets `cleanUrls` and sends `no-cache, no-store, must-revalidate` for
`/sw.js` so service-worker updates ship immediately.

Voice caveat (keep the PWA copy honest): the desktop app defaults to Google Web Speech
for speech recognition, so the default voice path is cloud. Switching the voice engine to
Vosk or SAPI makes recognition fully local. Camera frames and the intent engine are always
local.

Rebuild the desktop binary with `build_app.py` (PyInstaller), republish the release with
`gh release create`, then update the `href` in `index.html`.

## Notes

- **No external assets.** Fonts are the system stack, imagery is generated locally —
  the app is 100% offline-capable after first load.
- Gaze tracking and custom gestures are marked experimental in the UI and ship
  behind a flag in the desktop product.
