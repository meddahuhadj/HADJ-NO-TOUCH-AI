# HADJ No-Touch: التحكم في الحاسوب بدون لمس

تحكم كامل في Windows 10/11 **بالصوت وإيماءات اليد**، دون فأرة ولا لوحة مفاتيح، و**دون إنترنت**.

- 🔒 **الخصوصية:** كل النماذج على جهازك. لا يُرسل أي شيء للخارج، ولا يُحفظ أي تسجيل صوتي أو صورة كاميرا.
  (التطبيق يمنع نفسه برمجياً من فتح أي اتصال شبكي خارجي.)
- ♿ **مصمم لذوي الإعاقة الحركية:** كل شيء ممكن بالصوت وحده أو بالإيماءات وحدها، مع إيقاف طارئ دائم،
  وتأكيد قبل الإجراءات الخطرة، وخط كبير وتباين عالٍ، وواجهة عربية من اليمين لليسار.

## 1. التشغيل السريع (النسخة المحمولة)

**المتطلبات:** Windows 10/11 (64-bit)، ميكروفون، كاميرا ويب (اختيارية للإيماءات)، ذاكرة 4GB أو أكثر
(يستخدم التطبيق نحو 1.5GB، و2GB أثناء الإملاء)، ونحو 1.5GB من مساحة القرص.

1. فك ضغط `HADJ-NoTouch-portable.zip` في أي مجلد (أو على ذاكرة USB). **لا يحتاج تثبيتاً ولا Python.**
2. شغّل `HADJ-NoTouch.bat` (نافذة سوداء تظهر للحظة ثم تختفي، وهذا طبيعي).
   للتشخيص: `HADJ-NoTouch-debug.bat` يعرض نافذة أوامر ويكتب سجلاً مفصلاً.
3. تظهر أيقونة ميكروفون في شريط النظام بجانب الساعة. انتظر حتى تصبح **خضراء** (5 إلى 20 ثانية لتحميل النموذج العربي).

| لون الأيقونة | المعنى |
|---|---|
| 🟢 أخضر | يستمع لكلمة التنبيه |
| 🔵 أزرق | سمع كلمة التنبيه وينتظر الأمر |
| 🟣 بنفسجي | وضع الإملاء |
| 🔷 أزرق مخضر | الشبكة الصوتية ظاهرة |
| 🟡 أصفر | جارٍ التحميل |
| ⚪ رمادي | التحكم متوقف مؤقتاً |
| 🔴 أحمر | خطأ (انظر التلميح عند المرور على الأيقونة) |

4. قل: «**حاسوب، افتح المفكرة**».

> لتشغيله تلقائياً مع Windows: ضع اختصاراً لـ `HADJ-NoTouch.bat` في مجلد `shell:startup`.

كل إعداداتك وسجلاتك تُحفظ في `user_data\` بجانب البرنامج، فنقل المجلد ينقل كل شيء.

**محتوى المجلد:** `runtime\` (مفسّر Python الرسمي الموقَّع + المكتبات)، `app\` (كود التطبيق)،
`models\` (نماذج الصوت واليد)، `user_data\` (إعداداتك وسجلاتك).
يظهر التطبيق في مدير المهام باسم `pythonw.exe`.

> **لماذا ليس ملف .exe؟** «التحكم الذكي في التطبيقات» (Smart App Control) في Windows 11 يمنع الملفات التنفيذية
> غير الموقَّعة. هذه النسخة تعمل عبر مفسّر Python الرسمي الموقَّع من Python Software Foundation، فلا تُمنع.

## 2. الأوامر الصوتية

قل **كلمة التنبيه** ثم الأمر في جملة واحدة: «**حاسوب، انسخ**»،
أو قل «حاسوب» وانتظر الصوت القصير ثم الأمر.
بعد أي أمر تبقى **6 ثوانٍ** لأوامر متتالية دون كلمة التنبيه («مرر للأسفل»… «مرر للأسفل»).

- التشكيل والهمزات والتاء المربوطة لا تهم: «أغلق النافذة» = «اغلق النافذه».
- كلمات المجاملة مقبولة: «من فضلك انسخ»، «انسخ لو سمحت».
- يُقبل «الحاسوب» و«يا حاسوب».
- لتغيير كلمة التنبيه أو اللغة: من نافذة الإعدادات. للتبديل السريع قل «**حاسوب، بدّل اللغة**».

| الفئة | بالعربية | English |
|---|---|---|
| تطبيقات | افتح/شغّل [اسم] | open/launch [name] |
| بحث وكتابة | ابحث عن [نص] · اكتب [نص] | search for [text] · type [text] |
| نوافذ | أغلق النافذة · صغّر · كبّر · بدّل النافذة · النافذة السابقة · سطح المكتب | close window · minimize · maximize · switch window · previous window · show desktop |
| تبويبات | تبويب جديد · أغلق التبويب | new tab · close tab |
| تحرير | انسخ · الصق · قص · تراجع · أعد · احفظ · حدد الكل · احذف⚠ | copy · paste · cut · undo · redo · save · select all · delete⚠ |
| مفاتيح | إدخال · اخرج · الحقل التالي · الصفحة التالية/السابقة | enter · escape · tab · page down/up |
| فأرة | انقر · انقر مرتين · انقر بالزر الأيمن · مرّر للأسفل/للأعلى | click · double click · right click · scroll down/up |
| عرض | كبّر الخط · صغّر الخط | zoom in · zoom out |

**فتح التطبيقات:** يفهرس التطبيق كل برامج قائمة ابدأ تلقائياً، مع مطابقة تقريبية
(«افتح كروم»، «افتح vs code»، «open exel» → Excel). والأسماء العربية الشائعة معرّفة مسبقاً
(المفكرة، الحاسبة، الرسام، الإعدادات، مستكشف الملفات…)، ويمكنك إضافة أسمائك (القسم 7).

**الاستماع المستمر:** قل «حاسوب، استماع مستمر» لتنفيذ كل عبارة دون كلمة تنبيه.
هذا مريح لكنه أكثر عرضة للتنفيذ الخاطئ عند الحديث مع الآخرين. قل «أوقف الاستماع المستمر» للعودة.

## 3. الإملاء

1. ضع المؤشر في حقل نصي (المفكرة، Word، المتصفح…).
2. قل «**حاسوب، ابدأ الإملاء**»، فتصبح الأيقونة 🟣.
3. تكلّم بجمل طبيعية **دون** كلمة التنبيه، وسيُكتب كلامك.
4. للخروج قل «**أوقف الإملاء**». ما قلته قبلها يُكتب كاملاً.

| تقول | يُكتب |
|---|---|
| فاصلة · فاصلة منقوطة · نقطة · نقطتان | ، · ؛ · . · : |
| علامة استفهام · علامة تعجب | ؟ · ! |
| سطر جديد · فقرة جديدة | سطر جديد · سطران |
| افتح قوس · أغلق قوس · علامة تنصيص · شرطة | ( · ) · " · - |
| «امسح ذلك» | يحذف آخر جملة كُتبت |

بالإنجليزية: comma, period / full stop, question mark, new line, new paragraph, scratch that.

- أثناء الإملاء تُكتب كلمات الأوامر («انسخ»…) نصاً. **لتنفيذ أمر قل كلمة التنبيه قبله**: «حاسوب احفظ».
- الإملاء يعمل **بلا انتظار**: أكمل كلامك والجمل تُكتب بالترتيب عند جاهزيتها، والشريط يعرض «جارٍ تحويل N جملة».
- «توقف» يلغي أي نص لم يُكتب بعد، فلا يُكتب شيء بعد الإيقاف الطارئ.

**المحرك** (من الإعدادات ← الصوت والإملاء):
- **Whisper** (افتراضي): دقيق، ويضيف الترقيم تلقائياً، لكنه يستغرق بضع ثوانٍ لكل جملة على معالج بلا GPU.
- **Vosk**: فوري، لكنه أقل دقة وبلا ترقيم تلقائي.

## 4. الشبكة الصوتية

للنقر في أي مكان بالصوت وحده. قل «**حاسوب، اعرض الشبكة**»:

```
 1 | 2 | 3
 4 | 5 | 6
 7 | 8 | 9
```
- قل **رقماً** («خمسة» أو «5»): ينتقل المؤشر لوسط الخانة، وتنقسم إلى 9 خانات أصغر. كرّر حتى تصل للهدف.
- ثم «**انقر**» · «**انقر مرتين**» · «**انقر يمين**» · «**حرّك**» (تحريك دون نقر).
- «**رجوع**» للمستوى السابق · «**إلغاء**» للإخفاء. تختفي تلقائياً بعد 30 ثانية دون كلام.
- لا حاجة لكلمة التنبيه أثناء ظهور الشبكة.

## 5. الإيماءات والمعايرة

اجلس أمام الكاميرا على بعد 40 إلى 80 سم، مع إضاءة أمامية، وارفع يدك وراحتها نحو الشاشة.

| الإيماءة | الإجراء (قابل للتغيير) |
|---|---|
| ☝️ السبابة ممدودة (باقي الأصابع مطوية) | تحريك المؤشر |
| 🤏 قرص الإبهام مع السبابة ثم الإفلات | نقرة (قرصتان سريعتان = نقرة مزدوجة) |
| 🤏 قرص مع **الإبقاء** أو التحريك | سحب وإفلات |
| قرص الإبهام مع **الوسطى** | نقرة يمنى |
| ✌️ السبابة والوسطى ممدودتان + تحريك اليد للأعلى/للأسفل | تمرير |
| ✋ سحب اليد المفتوحة بسرعة يميناً / يساراً | النافذة التالية / السابقة |
| 🤏🤏 قرص بكلتا اليدين ثم إبعادهما / تقريبهما | تكبير / تصغير |
| ✋ كف مفتوح لثانيتين | إظهار سطح المكتب |
| ✊ **قبضة** لنصف ثانية | **إيقاف مؤقت فوري** لكل التحكم |
| ✋ كف مفتوح لثانية (أثناء الإيقاف) | استئناف |

- الكف المفتوح لا يحرك المؤشر، فيمكنك «رفع» يدك وإعادة وضعها.
- النقرة تقع حيث كان المؤشر **قبل** القرص، فلا تنزاح بحركة الأصابع.
- إذا اختفت اليد أثناء السحب يُحرَّر الزر تلقائياً، ولا تحدث أي نقرة أثناء التكبير بيدين.
- **منطقة التحكم:** جزء صورة الكاميرا الذي يقابل كامل الشاشة. تصغيرها يعني حركة أقل لعبور الشاشة.

### المعايرة (أقل من 20 ثانية، دون لمس)
قل «**حاسوب، معايرة**» واتبع التعليمات:
1. ✋ يد مفتوحة أمام الكاميرا.
2. 🤏 الإبهام يلمس السبابة.
3. ☝️ السبابة ممدودة والإبهام بعيد.
4. ☝️ حرّك السبابة ببطء إلى زوايا المنطقة المريحة لك.

تُحسب عتبة القرص الخاصة بيدك ومنطقة تحكم تناسب مدى حركتك، وتُحفظ **تلقائياً** بعد 5 ثوانٍ.
إن لم تكن النتيجة واضحة تبقى الإعدادات السابقة، مع توضيح السبب (إضاءة، يد غير مرئية…).
**يُنصح بالمعايرة عند أول استخدام وعند تغيّر مكان الجلوس أو الإضاءة.**

## 6. التحكّم بالنوافذ والشاشات

كل الأوامر تعمل على **النافذة الأمامية** (التي تنظر إليها الآن).

### النوافذ

| تقول | ما يحدث |
|---|---|
| «انتقل الى **المتصفح**» | يرفع نافذة تحمل هذا الاسم (أو أي جزء منه) |
| «النافذة لليسار» · «لليمين» · «للاعلى» | يثبّتها في نصف الشاشة |
| «النافذة في الزاوية العليا اليسرى» (وبقية الزوايا) | يثبّتها في ربع الشاشة |
| «ضع النافذة في الوسط» | يتوسّطها في مساحة عمل شاشتها |
| «حرك النافذة لليمين/لليسار/للاعلى/للاسفل» | إزاحة 80 بكسل |
| «وسّع النافذة» · «قلّص النافذة» | تكبير/تصغير تدريجي |
| «النافذة فوق كل شيء» | تثبيت فوق النوافذ الأخرى |
| «ارجع النافذة» | ترجعها من «ملء الشاشة» إلى حجمها السابق |

### الشاشات وأسطح المكتب

| تقول | ما يحدث |
|---|---|
| «انقل النافذة للشاشة الثانية» · «**الرئيسية**» | ينقلها لشاشة بعينها |
| «وسّع الشاشتين» · «كرر الصورة على الشاشتين» | تبديل طريقة عرض الشاشات |
| «سطح المكتب التالي/السابق» · «مكتب جديد» | تنقّل بين أسطح المكتب الافتراضية |
| «اغلق المكتب الافتراضي» | **يحذفه** (يطلب تأكيداً) |

### السطوع والوضع الداكن والصوت

| تقول | ما يحدث |
|---|---|
| «ارفع سطوع الشاشة» · «اخفض سطوع الشاشة» | ±10% |
| «السطوع نص» · «السطوع كامل» | 40% / 100% |
| «شغل الوضع الداكن» · «الوضع الفاتح» | يبدّل سمة Windows (يلزم إعادة تشغيل بعض التطبيقات) |
| «اطفي الشاشة» · «شغل الشاشة» | أي حركة فأرة تُوقظها |
| «كتم الميكروفون» · «افتح الميكروفون» | **يبدّل** الكتم (لا يقرأ الحالة) |

### حدود يجب معرفتها
- **الميكروفون:** التبديل فقط. لا يمكن ضبط حجم الصوت بنسبة مئوية أو قراءة حالة الكتم دون مكتبة `pycaw` (اختيارية). أمر الصوت العام (`volume_up`/`volume_down`) يبقى يعمل باختصارات المفاتيح.
- **السطوع:** يعتمد على WMI، فقد يستغرق نحو ثانيتين لكل أمر، ولا يعمل على شاشات لا تدعمه.
- **«وسّع الشاشتين»:** يُنفَّذ باختصار `Win+Shift+→` أي «ادفع النافذة إلى شاشة ثانية»، وهو **ليس** تبديلاً حقيقياً لوضع «تمديد». لتغيير الوضع فعلياً: افتح إعدادات العرض ثم اختر الوضع المطلوب.
- **الانتقال إلى نافذة بالاسم:** قد يرفض Windows رفع النافذة إن لم يكن هناك إذن مقدَّم. إن لم تعمل من الصوتي، جرّب من أيقونة النظام أو بعد اختصار لوحة مفاتيح.
- **أسطح المكتب الافتراضية:** تحتاج تفعيل تبويب «أسطح المكتب الافتراضية» في إعدادات Windows.

## 7. الأمان

| الوسيلة | كيف |
|---|---|
| **إيقاف طارئ صوتي** | قل «**توقف**» أو «توقف فوراً»، دون كلمة تنبيه، في أي وضع |
| **إيقاف طارئ بالإيماءة** | ✊ قبضة لنصف ثانية |
| **إيقاف طارئ من لوحة المفاتيح** (للمرافق) | **Ctrl+Alt+Shift+P** (قابل للتغيير) |
| الاستئناف | «حاسوب، استأنف» أو ✋ كف مفتوح لثانية أو الاختصار نفسه |

- عند الإيقاف: يُحرَّر أي زر فأرة أو مفتاح مضغوط، ويُلغى أي تأكيد معلق أو إملاء أو شبكة.
- الإجراءات الخطرة (حذف، إغلاق دون حفظ، إطفاء، قفل الشاشة) تطلب تأكيداً صوتياً أو بصرياً.
- **تنبيه:** «اقفل الشاشة» قد يمنعك من العودة إن لم تستطع إدخال كلمة المرور. فعّل Windows Hello (التعرف على الوجه) أولاً.
- يعمل نسخة واحدة فقط من التطبيق في الوقت نفسه.

## 8. الإعدادات والتخصيص

### نافذة الإعدادات
من قائمة الأيقونة ← «**الإعدادات…**» أو قل «**حاسوب، إعدادات التطبيق**». التبويبات:
- **عام:** لغة الواجهة ولغة الأوامر، وكلمات التنبيه، والاستماع المستمر، والأصوات، و**حجم الخط**، و**التباين العالي**.
- **الصوت والإملاء:** الميكروفون، وتجاهل الضوضاء، ودقة المطابقة، ومحرك الإملاء ونموذجه.
- **الكاميرا:** رقم الكاميرا، واليد المتحكمة، وثبات المؤشر، ومنطقة التحكم، وعتبة القرص، وعكس التمرير، والمعايرة.
- **الإيماءات:** اربط كل إيماءة بأي إجراء، أو عطّلها.
- **الأمان:** اختصار الإيقاف الطارئ، والتأكيد قبل الإجراءات الخطرة.

معظم التغييرات تُطبَّق فوراً. أما لغة الواجهة وحجم الخط والتباين فتُطبَّق عند إعادة تشغيل التطبيق.

### ملفات الإعدادات (للمتقدمين)
- `user_data\config.yaml`: اكتب فيه فقط ما تريد تغييره. كل الخيارات موثقة في
  [`src/config/default_config.yaml`](src/config/default_config.yaml) (وفي النسخة المحمولة: `_internal\config\default_config.yaml`).
- **أسماء تطبيقات إضافية:**
  ```yaml
  app_aliases:
    بريدي: Outlook
    المحاسبة: "C:\\Program Files\\MyApp\\app.exe"
  ```

### عام
- Windows فقط حالياً. طبقة النظام معزولة في `src/os_layer/` لتسهيل إضافة Linux/macOS.
- بعض التطبيقات التي تعمل كمسؤول (Administrator) لا تقبل الإدخال من تطبيق عادي (قيد في Windows).
  شغّل HADJ-NoTouch كمسؤول إن احتجت التحكم بها.
- الذاكرة: نحو 1.5GB (+500MB أثناء الإملاء). على الأجهزة ذات 4GB أغلق البرامج الأخرى.

## 10. التشخيص وحل المشكلات

| المشكلة | الحل |
|---|---|
| الأيقونة تبقى صفراء | تحميل النموذج العربي بطيء على القرص البطيء أو مع ذاكرة قليلة. انتظر، أو راجع السجل |
| «لا ترسل الكاميرا صورة» | غطاء الكاميرا مغلق، أو مفتاح تعطيلها مفعّل، أو منع في إعدادات Windows ← الخصوصية ← الكاميرا ← «السماح لتطبيقات سطح المكتب» |
| «الكاميرا بطيئة» | تطبيق آخر يستخدمها. أغلقه |
| لا يستجيب للصوت | تحقق من الميكروفون الافتراضي في Windows، أو اختره في الإعدادات؛ وتأكد أن الأيقونة ليست رمادية (متوقف) أو بنية (مكتوم) |
| الأوامر تُفهم خطأ | شغّل بـ `--debug` وراجع ما سُمع في السجل، ثم أضف تلك الصيغة كأمر مخصص |

- **الفحص الذاتي:** `HADJ-NoTouch-debug.bat --selftest` يحمّل كل نموذج ويشغّله مرة (دون ميكروفون ولا كاميرا)،
  ويكتب تقريراً في `user_data\logs\selftest.txt`. استخدمه بعد النقل لجهاز جديد.
- **السجل:** `user_data\logs\app.log` (نص الكلام يُسجَّل فقط مع `--debug`).
- **الانهيارات:** `user_data\logs\crash.log`.
- **قياس الكاميرا** (من المصدر): `python scripts\bench_vision.py 10`.
- **اختبار العمل دون إنترنت:** شغّل `offline_test.ps1` الموجود بجانب البرنامج. يراقب كل اتصالات التطبيق ويتحقق
  من جاهزيته. وكمسؤول: `offline_test.ps1 -Block` يحظر التطبيق في جدار الحماية مؤقتاً أثناء الاختبار.

## 11. للمطورين: البناء من المصدر

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python scripts\download_models.py     # مرة واحدة (~1.2GB). الإنترنت مطلوب هنا فقط
run.bat                                             # أو: .venv\Scripts\python src\main.py --debug
.venv\Scripts\python -m pytest                      # الاختبارات
powershell -ExecutionPolicy Bypass -File scripts\build.ps1   # dist\HADJ-NoTouch-portable.zip
```

خيارات التشغيل: `--debug` (سجل مفصل)، `--selftest` (فحص النماذج)، `--vision-dry-run` (تتبع اليد دون تحريك المؤشر)،
`--exit-after N` (خروج تلقائي بعد N ثانية، للاختبار).

**وضعا البناء:**
- `build.ps1` (افتراضي، `-Mode python`): مفسّر Python الموقَّع + الكود + المكتبات. يستغرق بضع دقائق،
  ويعمل مع Smart App Control. الناتج: مجلد ~1.9GB وملف مضغوط ~1GB (معظمه النماذج).
- `build.ps1 -Mode pyinstaller`: ملف `HADJ-NoTouch.exe` واحد. يستغرق 20 إلى 40 دقيقة، و**يحتاج توقيعاً رقمياً**
  (شهادة Code Signing) لكي لا يمنعه Smart App Control على أجهزة Windows 11.

### البنية
```
src/
  audio/      التقاط الميكروفون (WinMM)، VAD، Vosk، Whisper — عملية مستقلة
  vision/     الكاميرا، MediaPipe، تصنيف الإيماءات، المرشح، المؤشر، المعايرة — عملية مستقلة
  commands/   المحلل، بوابة التنبيه، الموزّع، الإجراءات، الإملاء، الشبكة، الأوضاع
  os_layer/   الواجهة المجردة + تنفيذ Windows (SendInput، النوافذ، فهرسة التطبيقات)
  ui/         الأيقونة، الشريط، الشبكة، التأكيد، المعايرة، الإعدادات
  config/     المخطط والإعدادات والأوامر الافتراضية
  core/       الأحداث، الاتصال بين العمليات، المتحكم، حارس عدم الاتصال
tests/        اختبارات وحدة وتكامل (تسجيلات صوتية حقيقية، نقاط يد اصطناعية)
```
- الصوت والرؤية يعملان في **عمليات مستقلة**، فلا يتأثر أحدهما بالآخر ولا تتجمد الواجهة.
- العمليات الفرعية **لا ترث** أي قنوات من الرئيسية: تهيئ جهازها أولاً ثم تتصل عبر أنبوب مسمّى محمي بمفتاح عشوائي.
  السبب أن بعض برامج تشغيل الصوت والكاميرا تُفسد المقابض الموروثة أثناء التهيئة (انظر `src/core/ipc.py`).
- المؤشر والنقرات تُنفَّذ داخل عملية الرؤية مباشرة لأقل تأخير (نحو 50ms معالجة لكل إطار).
